# 📄 Desafio 2 - Criando uma Página Web

Projeto desenvolvido como parte do desafio da **Empresa Compass**, utilizando **HTML, CSS e JavaScript**.  
O objetivo é aplicar conceitos fundamentais de desenvolvimento front-end para criar uma página web funcional e estilizada.

---

## 🚀 Tecnologias Utilizadas
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização e responsividade  
- **JavaScript (ES6+)** → Interatividade e manipulação do DOM  

---

## 📂 Estrutura do Projeto
Desafio-2-Criando-uma-pagina-web/
│
├── index.html        # Página principal
├── styles.css        # Estilos da página
├── scripts.js        # Lógica e interatividade
├── images/           # Imagens utilizadas no projeto
└── README.md         # Documentação do projeto



---

## 🎯 Funcionalidades
- Estrutura semântica em HTML  
- Estilização com CSS, incluindo cores, fontes e layout responsivo  
- Interatividade com JavaScript (ex.: manipulação de elementos, eventos)  
- Uso de imagens para enriquecer o conteúdo visual
